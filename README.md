# علاء الدين — سوبر ماركت عربي PWA

تطبيق مبدئي Mobile-first باللغة العربية فقط، يدعم RTL، كتالوج منتجات، أقسام، فرز، صفحة منتج، سلة، حد أدنى للطلب، شحن مجاني بعد حد معين، Checkout بالدفع عند الاستلام، وإرسال الطلب عبر واتساب.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يظهر في الطرفية.

## بناء نسخة الإنتاج

```bash
npm run build
npm run preview
```

مجلد الإنتاج النهائي: `dist/`.

## أهم الإعدادات

عدّل الملف:

`src/config/store.ts`

وفيه:
- اسم المتجر
- رقم واتساب
- العملة
- الحد الأدنى للطلب
- حد الشحن المجاني
- تكلفة التوصيل

رقم واتساب يجب أن يكون بصيغة دولية بدون علامة +، مثال مصر:
`2010XXXXXXXX`

## المنتجات والأقسام

- الأقسام: `src/data/categories.ts`
- المنتجات: `src/data/products.ts`

استبدل الصور التجريبية بمسارات الصور الحقيقية داخل مجلد `public/images/`.

## المسارات

- `/` الرئيسية
- `/categories` الأقسام
- `/category/:categoryId` منتجات القسم
- `/product/:slug` صفحة المنتج
- `/search?q=` البحث
- `/cart` السلة
- `/checkout` إتمام الطلب
- `/confirmation/:orderId` تأكيد الطلب
- `/account` حسابي

## ملاحظات MVP

- لا يوجد Backend أو تسجيل دخول في النسخة الحالية.
- السلة وآخر طلب محفوظان في `localStorage`.
- الدفع عند الاستلام فقط.
- إرسال واتساب يتم من جهاز العميل باستخدام `wa.me`.
- يجب وضع رقم واتساب الحقيقي قبل النشر.
- تكلفة التوصيل الافتراضية 30 ج.م لأن السعر العادي لم يتم تحديده في المتطلبات.
