# جدولة معالج انتهاء صلاحية نقاط الولاء (Railway Cron)

هذا الملف توثيق وتوصية فقط — **مفيش جدولة (Railway Cron Job أو غيرها) اتضافت أو
اتفعّلت تلقائياً كجزء من هذا التغيير**. أمر `npm run loyalty:expire` موجود وجاهز، لكنه
مجرد سكريبت يدوي حتى يتم ربطه فعلياً بجدولة خارجية بمعرفة صاحب المشروع.

## لماذا مفيش scheduler جوه التطبيق نفسه

نفس مبدأ `db:cleanup` و`notify:abandoned-cart` الموجودين بالفعل: عملية السيرفر (Express)
مسؤوليتها خدمة الطلبات بس — أي مهمة دورية (تنظيف، تذكير، انتهاء صلاحية) بتُشغَّل كسكريبت
مستقل منفصل تماماً عن عملية السيرفر، بمعرفة جدولة خارجية (Railway Cron Job هنا). ده بيمنع
مشاكل زي: تكرار التشغيل لو أكتر من نسخة (replica) من السيرفر شغّالة في نفس الوقت، أو تعليق
عملية السيرفر الأساسية بمهمة دورية طويلة.

## إعداد Railway Cron Job (خطوات يدوية)

1. من لوحة تحكم Railway → المشروع → أضف خدمة جديدة من نوع "Cron Job" (منفصلة عن خدمة
   الويب الأساسية، بس بتشارك نفس الـ repo/environment variables زي `DATABASE_URL`).
2. Build command: نفس أمر بناء السيرفر الحالي (`npm install && npm run build --prefix server`)
   أو استخدم نفس صورة/بناء خدمة الويب الأساسية لو Railway بيسمح بمشاركتها.
3. Start command: `npm run loyalty:expire --prefix server`
4. الجدولة الموصى بها: مرة واحدة يومياً (مثلاً الساعة 3 صباحاً بتوقيت القاهرة) — كافية
   تماماً لميزة زي دي، مفيش داعي لتكرار أعلى من كده.
5. تأكد إن متغير `DATABASE_URL` نفسه المُستخدم في خدمة الويب الأساسية متاح لخدمة الـ Cron
   الجديدة دي — بدونه هتفشل فوراً بنفس رسالة الخطأ الموجودة في `db.ts`.

## التحقق من إن المعالج شغّال صح فعلاً

بعد الربط بالجدولة، راقب لوجات خدمة الـ Cron على Railway بعد أول تشغيلة متوقعة — السكريبت
بيطبع سطر واحد واضح زي:

```
loyalty expiry: processed 12 expired lot(s) across 1 batch(es)
```

لو انتهاء الصلاحية معطّل من إعدادات المتجر (`loyalty_expiry_enabled = false`)، السكريبت
بيطلع "processed 0 expired lot(s)" فوراً من غير أي استعلام قاعدة بيانات إضافي — ده سلوك
متوقع، مش خطأ.

## ما لم يتم فعله عمداً في هذا التغيير

- لم يتم إنشاء أي خدمة Cron فعلية على Railway.
- لم يتم التأكد من وجود جدولة فعلية شغّالة في الإنتاج — أي ادعاء بخلاف ذلك غير دقيق لحد
  ما يتم الإعداد اليدوي فوق فعلياً والتحقق منه.
